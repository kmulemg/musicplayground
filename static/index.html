设置

音乐源

按平台类型分组选择要启用的音乐源。每组可整体全选/取消，也可单独勾选。保存后会重建客户端。

无需 Cookie 需会员 Cookie（高清 / 无损 / 已购买） 需夸克网盘 Cookie（更高清） 无cookie仅预览 / 不可下载

依赖管理

检查 Python 依赖和外部 CLI 工具的安装状态，或一键更新 musicdl / requirements.txt 中的依赖。执行期间请勿重复操作。

服务

重启或终止服务会中断当前请求。重启完成后页面自动刷新，终止后需手动刷新页面。

Cookie 管理

为各音乐平台录入登录 Cookie。Apple Music 需要 media-user-token；支持 JSON（{"media-user-token": "xxx"}）或 k=v; k2=v2 字符串格式。修改后会自动重建客户端。

下方 Cookie 录入列表仅列出官方文档支持的源；Spotify / YouTube / 喜马拉雅 等官方不提供 cookie 录入的源不在此列。列表底部「夸克网盘」用于给聚合下载站（MyFreeMP3 / Buguyy 等）配置 quark_parser_config，登录 https://pan.quark.cn 后导入 Cookie 即可下载更高清文件。
